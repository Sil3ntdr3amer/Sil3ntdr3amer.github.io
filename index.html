C++ Console Application

NotSoMARVELous

The project was a fighting game that allowed the user to select a hero, weapon, and armor; and the villain was randomly selected. Each character had a certain amount of health and damage. The weapons and armor added or subtracted health and damage depending on what you select. You would then fight and choose to either attack or defend until either the hero or villain died.

Key Features

  • Character, weapon, and armor selections.
  • Fight using attack and defend mechanics.
  • I created a function that validates user input by capturing it as a string and using a try-catch block with std::stoi to safely convert it into an integer. If the conversion succeeds and the number falls within your specified min and max bounds, it is returned immediately; otherwise, the function catches any conversion errors, displays a helpful error message, and loops until the user enters a valid choice.

What I Learned

One challenge that I faced was that the user was able to fight without ever selecting a hero, weapon, or armor. I fixed this by only allowing the user to select Fight which forces the user to have to select a hero, then a weapon, and finally an armor. Once the user selected these things, the fight method would execute. This taught me how to use switch loops in a way that forces the user to do things before executing a method.

C++ Desktop Application (wxWidgets)

Calculator App

A full-featured graphical calculator built with C++ and wxWidgets. The application supports basic arithmetic, trigonometric functions, and complex expressions while using clean architecture and thorough testing.

Key Features

  • Custom button layout created with wxGridSizer (6×4 grid) and a dedicated ButtonFactory class for clean UI construction.
  • Expression evaluation powered by a full Shunting-Yard algorithm implementation that correctly handles operator precedence, unary operators, and functions (sin, cos, tan).
  • Robust error handling for invalid input (multiple decimals, consecutive operators, division/modulo by zero, unknown functions, empty input, etc.).
  • Comprehensive unit tests covering both the ButtonFactory and CalculatorProcessor using Microsoft’s C++ Unit Test Framework.

What I Learned

This project taught me how to build a real desktop application with wxWidgets, including creating and organizing buttons with wxGridSizer and binding events properly. I implemented the Shunting-Yard algorithm to correctly parse and evaluate mathematical expressions, which deepened my understanding of stacks, operator precedence, and expression trees. I also applied design patterns (Factory for button creation and Singleton for the calculator processor) to keep the code modular and maintainable. Writing unit tests for both the UI factory and the calculation engine helped me catch edge cases early, and building solid error handling made the application much more reliable. Overall, this project significantly improved my skills in GUI development, algorithm implementation, testing, and clean C++ design.
